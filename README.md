# FocusKeep

一个 Windows 托盘小工具：让屏幕保持常亮，需要时一键锁住键盘，并为 OLED 屏幕提供周期性的"护屏休息"。

单文件 exe，免安装、免配置，双击即用 · 适用于 Windows 10 / 11 · MIT License

## 功能

**屏幕常亮**
在系统允许的范围内阻止屏幕自动关闭和系统休眠，适合长时间看资料、跑任务、投屏时使用。

**键盘锁定**
吞掉所有键盘输入（鼠标不受影响），适合"人暂时离开又不想被碰键盘"的场景。四种方式可以随时解锁，最长锁定时间到点也会自动解锁。

**OLED 护屏**
在你离开电脑时，用纯黑遮罩让屏幕周期性"休息"一段时间的，降低 OLED 长期显示静止画面导致的烧屏风险。黑屏期间不改变系统电源状态，后台任务、远程连接都不受影响。

## 下载与使用

前往 [Releases](../../releases) 下载 `FocusKeep.exe`，双击运行即可——程序只在托盘出现，没有主窗口。

| 操作 | 效果 |
|---|---|
| 左键 / 右键单击托盘图标 | 打开菜单 |
| 右键菜单 → 关闭 FocusKeep | 退出程序 |

> 找不到图标？点任务栏右下角的 `^` 展开溢出区，把 FocusKeep 拖到任务栏上固定；
> 或者运行 `FocusKeep.exe --menu` 直接弹出菜单。

### 托盘菜单

```
屏幕常亮中 · 护屏每 20 分钟
──────────────
● 开启屏幕常亮 / ○ 关闭屏幕常亮
OLED 护屏　每 20 分钟 ▸
     关闭 / 每 10 分钟 · 黑屏 20 秒 / 每 20 分钟 · 30 秒 / 每 30 分钟 · 45 秒 / 每 60 分钟 · 60 秒
     立即休息一次（黑屏 30 秒）
──────────────
锁定键盘　Ctrl+Alt+L
最长锁定 60 分钟 ▸ 5 / 15 / 30 / 60 / 120 / 240 / 480
──────────────
项目主页 / 打开配置文件 / 关于
──────────────
退出 FocusKeep
```

锁定键盘后，菜单第一项会变成加粗的 **解锁键盘**。

### 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + L` | 锁定键盘（会先弹确认框，默认按钮是"否"）；**锁定期间再按一次 = 解锁** |
| `Ctrl + Alt + Shift + U` | 解锁（仅锁定期间有效） |

> 锁定期间所有按键都会被钩子拦下，所以不要在锁定状态下指望其它快捷键生效。
> 鼠标始终可用，最稳妥的解锁方式是托盘菜单。

### 命令行

| 命令 | 作用 |
|---|---|
| `FocusKeep.exe` | 启动；若已在运行则只提示一次 |
| `FocusKeep.exe --menu` | 让正在运行的实例在鼠标位置弹出菜单 |
| `FocusKeep.exe --rest` | 让正在运行的实例立刻黑屏休息一次（可绑定快捷键或计划任务） |
| `FocusKeep.exe --quit` | 让正在运行的实例退出 |
| `FocusKeep.exe --selftest` | 无界面自检，退出码 0 表示全部通过 |
| `FocusKeep.exe --blank-preview 3` | 铺 3 秒黑色遮罩，用来确认护屏能覆盖所有显示器 |
| `FocusKeep.exe --icon-preview <目录>` | 导出四种状态的图标 PNG |

## OLED 护屏说明

"屏幕常亮"在 OLED 上恰恰是烧屏的典型条件：同一幅画面在同一批像素上连续点亮几个小时。
护屏的做法是**在你离开时**用一块纯黑遮罩盖住全部显示器——OLED 上黑色意味着像素不发光，
这几十秒里屏幕几乎不产生老化，但常亮状态、后台任务、远程会话都不会中断。

**同时满足以下条件才会黑屏：**

| 条件 | 说明 |
|---|---|
| 屏幕常亮处于开启 | 常亮关掉后系统自己会熄屏 |
| 键鼠空闲 ≥ 1 分钟 | 人在操作时绝不打扰 |
| 前台不是全屏窗口 | 不挡视频、游戏、幻灯片放映（最大化窗口不算全屏） |
| 最近 45 秒内没有声音 | 不挡正在看/听的内容 |
| 距上次休息已满一个间隔 | 默认 20 分钟 |

黑屏期间动一下鼠标或按任意键会立刻恢复；「立即休息一次」则不受上述条件限制，
会跑满设定时长，想提前结束点一下鼠标即可（纯移动鼠标不算）。

~> 烧屏还和**亮度**与**静态 UI** 强相关：深色壁纸、隐藏桌面图标、任务栏自动隐藏、
把亮度控制在 40%~60%，这些和护屏一起用效果最好。

## 配置

配置文件位置按优先级自动选择（会实际探测可写性）：

1. 环境变量 `FOCUSKEEP_CONFIG_DIR` 指定的目录
2. exe 同目录下**已存在**的 `data\`（把程序放进 U 盘并建一个 `data` 文件夹即为便携版）
3. `%APPDATA%\FocusKeep\`
4. exe 同目录新建 `data\`
5. `%TEMP%\FocusKeep\`

右键菜单的「打开配置文件」可以直接编辑，改完重启程序生效：

```ini
# 键盘锁定硬超时（1-480 分钟），到点强制解锁
MaxLockMinutes=60

# OLED 护屏开关（1 开 / 0 关）
OledGuardEnabled=1
# 两次休息的最小间隔（5-180 分钟）
OledIntervalMinutes=20
# 每次休息的黑屏时长（10-180 秒）
OledBlankSeconds=30
```

同目录下的 `focuskeep.log` 是滚动日志（超过 256 KB 自动转存 `.old`），
每次护屏开始/结束都会记一行，方便确认它到底工作过没有。

## 常见问题

**托盘图标不见了？**
点任务栏右下角 `^` 展开溢出区，把图标拖到任务栏上固定；或运行 `FocusKeep.exe --menu`。
Windows 11 默认会把新程序的图标放进溢出区。

**杀毒软件报毒 / SmartScreen 提示未知发布者？**
全局键盘钩子是键盘记录器的典型技术特征，容易被启发式规则误判；exe 未做代码签名，
首次运行会被 SmartScreen 拦一下（"更多信息 → 仍要运行"）。这些都是预期行为。

**锁定键盘后怎么解锁？**
① 右键托盘图标 → 解锁键盘；② 按 `Ctrl + Alt + L` 或 `Ctrl + Alt + Shift + U`；
③ 到达「最长锁定」时间自动解锁；④ 锁屏 / 注销 / 断开远程会自动解锁。
实在不行，结束 FocusKeep 进程即可——钩子随进程一起消失。

**护屏一直没触发？**
先确认「屏幕常亮」是开着的、护屏开关没关；然后注意它只在键鼠空闲 1 分钟以上、
前台不是全屏、且没有声音时才触发。也可以用菜单里的「立即休息一次」直接验证。

**为什么挡不住 `Ctrl+Alt+Del`？**
这个组合由 Windows 在安全桌面（winlogon）处理，任何用户态程序都拦不住。
UAC 提示、登录界面同理。

---

## 限制

| 限制 | 原因 |
|---|---|
| 挡不住 `Ctrl+Alt+Del` / UAC / 登录界面 | 由安全桌面处理 |
| 挡不住任务管理器强杀进程 | 用户态钩子的必然结果 |
| 锁定期间按下的修饰键可能"残留" | 按下与抬起都被吞掉，解锁后按一下 `Shift` 即可 |
| 护屏只作用于本机显示器 | 不改变同一画面在其他设备上的显示 |
| 护屏不接管系统屏保 | 两者互不冲突，可以只留一个 |

## 构建

不需要 Visual Studio，也不需要 .NET SDK，用系统自带的 .NET Framework 编译器即可：

```powershell
pwsh -File .\build.ps1                 # 产物：bin\FocusKeep.exe
.\bin\FocusKeep.exe --selftest         # 自检，退出码 0 表示全部通过
```

> 请用 **PowerShell 7**（`pwsh`）执行：Windows PowerShell 5.1 会按 ANSI 读取脚本，中文注释会解析失败。

仓库结构：`src/` 是全部源码（C#，单文件类），`build.ps1` 是构建脚本，
`tools/` 放图标生成工具，`preview/` 是界面预览图。
