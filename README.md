# FocusKeep

Windows 托盘小工具：**屏幕常亮**、**键盘锁定**，以及给 OLED 屏准备的**护屏休息**。
单文件 exe（约 470 KB，图标已内嵌），不依赖任何运行时安装（系统自带 .NET Framework 4.x）。
**没有主窗口**，所有设置都在托盘右键菜单里（原生系统菜单）。

> 作者：**圣婴**　·　微信：`say007go`　·　项目主页：<https://github.com/say007go/FocusKeep>
> 版本：1.3.0　·　许可证：[MIT](LICENSE)

![屏幕常亮](preview/icon-On.png)　![已关闭](preview/icon-Off.png)　![键盘锁定](preview/icon-On-Locked.png)

蓝绿显示器 = 屏幕常亮中　·　灰色显示器 = 屏幕常亮已关闭　·　**右下角红色小锁 = 键盘已锁定**

> 键盘锁定是**角标**而不是整块换色：锁定的时候你依然能一眼看出屏幕常亮是开着的。

## 一、运行

双击 `bin\FocusKeep.exe`，程序直接进入托盘，**默认已开启屏幕常亮和 OLED 护屏**。

| 操作 | 效果 |
|---|---|
| 右键托盘图标 | 打开菜单（左键单击同样可以） |
| 双击托盘图标 | 打开菜单 |

### 托盘菜单

```
屏幕常亮中 · 护屏每 20 分钟        ← 当前状态
──────────────
● 开启屏幕常亮
○ 关闭屏幕常亮
OLED 护屏　每 20 分钟 ▸            ← 防烧屏，详见第二节
     关闭
     ──────────
     每 10 分钟 · 黑屏 20 秒
     每 20 分钟 · 黑屏 30 秒
     每 30 分钟 · 黑屏 45 秒
     每 60 分钟 · 黑屏 60 秒
     ──────────
     立即休息一次（黑屏 30 秒）
     键鼠空闲 1 分钟以上才自动触发（灰显说明）
────────────────
锁定键盘　Ctrl+Alt+L
最长锁定 60 分钟 ▸ 5/15/30/60/120/240/480
──────────────
项目主页（GitHub）
打开配置文件

──────────────
退出 FocusKeep
```

锁定键盘后，菜单第一项会变成加粗的 **解锁键盘**：

```
键盘已锁定 · 右键图标或按 Ctrl+Alt+L 解锁
──────────────
开启屏幕常亮 / 关闭屏幕常亮
OLED 护屏 ▸
──────────────
解锁键盘                          ← 加粗，鼠标点它即可解锁
（也可以按 Ctrl+Alt+Shift+U 或 Ctrl+Alt+L）
──────────────
```

### 原生菜单与「关于」

托盘菜单用的是 **Windows 原生菜单**（`TrackPopupMenu`）：外观完全跟随系统——Windows 11 上是圆角、系统主题色、系统动效，勾选区和对齐也由系统统一处理，不用自己画。

菜单底部两个入口：

- **项目主页（GitHub）**：直接用默认浏览器打开 <https://github.com/say007go/FocusKeep>；
- **打开配置文件**：用系统默认程序（通常是记事本）打开 `config.ini`，改完重启程序生效。

「关于 / 限制说明」用的是系统 **TaskDialog**：主标题是版本号，正文是开发者信息和项目地址，
「使用说明 / 限制」可以展开查看热键、图标含义、护屏原理和已知限制。**不显示本机任何路径**，方便开源分发。

### 热键

| 热键 | 作用 |
|---|---|
| `Ctrl + Alt + L` | 锁定键盘（弹确认框，默认按钮是"否"）；**锁定期间再按一次 = 解锁** |
| `Ctrl + Alt + Shift + U` | 解锁（仅锁定期间有效） |

> 锁定期间这两个组合都由键盘钩子自己判定——`RegisterHotKey` 那一路会被钩子吞掉收不到，
> 所以不要在锁定状态下指望别的全局热键有反应。鼠标始终可用，最稳的解锁还是右键托盘菜单。

### 命令行参数（含排障）

| 命令 | 作用 |
|---|---|
| `FocusKeep.exe` | 启动；已在运行则只弹一个提示气泡 |
| `FocusKeep.exe --menu` | 让已在运行的实例直接在鼠标位置弹出菜单 |
| `FocusKeep.exe --rest` | 让已在运行的实例立刻黑屏休息一次（可绑快捷键/计划任务） |
| `FocusKeep.exe --quit` | 让已在运行的实例退出 |
| `FocusKeep.exe --selftest` | 无界面自检（配置往返 / 图标 / 电源 API / 护屏探测） |
| `FocusKeep.exe --icon-preview <目录>` | 导出四种组合（常亮/关闭 × 是否锁定）图标 PNG |
| `FocusKeep.exe --blank-preview 3` | 立即铺 3 秒黑色遮罩，用来确认护屏能盖满所有显示器 |

> 找不到托盘图标时：点任务栏 `^` 展开，把 FocusKeep 拖到任务栏上固定；
> 或者直接 `FocusKeep.exe --menu` 把菜单叫出来。

## 二、OLED 护屏（防烧屏）

### 为什么需要它

"屏幕常亮"的含义是**屏幕永远不熄灭**。放在 OLED 上，这恰恰是烧屏的典型条件：
同一幅画面（任务栏、桌面图标、某个窗口的白色标题栏、幻灯片的一页）会在同一批像素上
连续点亮几个小时，亮度越高、时间越久，残留就越明显。

### 它怎么做

屏幕常亮期间，每隔一段时间（默认 20 分钟）用一块**纯黑遮罩**盖住所有显示器，持续 30 秒：

- OLED 上"黑"= 像素不发光，这 30 秒里屏幕几乎不产生任何老化，效果接近熄屏；
- 但**不改变系统的显示电源状态**，屏幕常亮照旧、下载/渲染/远程会话都不中断；
- 到点自动撤掉，**动一下鼠标或按任意键也会立刻消失**，不需要等满 30 秒。

### 什么时候才会黑屏（五个条件同时满足）

| 条件 | 说明 |
|---|---|
| 屏幕常亮处于开启 | 常亮关掉后系统自己会熄屏，不需要护屏 |
| 键鼠空闲 ≥ 1 分钟 | 人在操作时绝不打扰 |
| 前台不是全屏窗口 | 不挡视频、游戏、幻灯片放映（最大化窗口不算全屏） |
| 最近 45 秒内没有声音 | 不挡正在看/听的内容 |
| 距上次休息已满一个间隔 | 默认 20 分钟，可改 |

> 遮罩出现后的**第一次鼠标动作会被它"吃掉"**（当作唤醒），不会误点到下面的窗口——
> 这一点和屏保一致。

### 怎么调

右键菜单 → `OLED 护屏`：

- **关闭**：完全停用；
- 四档预设：`每 10 分钟 · 黑屏 20 秒` / `每 20 分钟 · 30 秒`（默认）/ `每 30 分钟 · 45 秒` / `每 60 分钟 · 60 秒`；
- **立即休息一次**：马上黑屏，**跑满设定秒数**（不受空闲/声音/全屏判断影响），
  想提前结束点一下鼠标即可——纯鼠标移动不算，避免刚点完菜单手一抖就没了。

判断标准很简单：**只要你不希望屏幕在你离开时长时间停在某一幅画面上，就开着它；
如果这台机器在跑监控大屏、演示机，不希望画面被遮，就关掉它。**

## 三、配置

位置按优先级自动挑选（会实际探测可写性，全失败才退化到临时目录）：

1. 环境变量 `FOCUSKEEP_CONFIG_DIR` 指定的目录（便携模式）
2. `%APPDATA%\FocusKeep\`
3. exe 同目录的 `data\`
4. `%TEMP%\FocusKeep\`

```ini
# MaxLockMinutes      : 键盘锁定硬超时（1-480 分钟），到点强制解锁
MaxLockMinutes=60

# OLED 护屏（1 开 / 0 关）
OledGuardEnabled=1
# 两次休息的最小间隔（5-180 分钟）
OledIntervalMinutes=20
# 每次休息的黑屏时长（10-180 秒）
OledBlankSeconds=30
```

同目录 `focuskeep.log` 是滚动日志（超过 256 KB 自动转存 `.old`）。
护屏每次开始/结束都会记一行，方便事后确认它到底工作过没有。

## 四、行为与边界

| 项目 | 说明 |
|---|---|
| 屏幕常亮 | `SetThreadExecutionState(ES_CONTINUOUS\|ES_SYSTEM_REQUIRED\|ES_DISPLAY_REQUIRED)`，每 20 秒重申，关闭时只回 `ES_CONTINUOUS` |
| OLED 护屏 | 纯黑全屏遮罩（`WS_EX_NOACTIVATE`，不抢焦点、不进 Alt+Tab），到点或有人操作即撤 |
| 键盘锁定 | 用户态低级键盘钩子 `WH_KEYBOARD_LL`，吞掉所有按键 |
| 解锁 | ①托盘菜单 ②`Ctrl+Alt+Shift+U` ③到达最长锁定时间自动解锁 ④锁屏/注销/断开远程自动解锁 |
| 鼠标 | **不受影响**，所以随时能从托盘菜单解锁；护屏的黑屏也是鼠标一动就消失 |

### 做不到的事

| 限制 | 原因 |
|---|---|
| 挡不住 `Ctrl+Alt+Del` | 该组合由 winlogon 在安全桌面处理 |
| 挡不住 UAC、登录界面 | 同上，安全桌面 / 其他会话 |
| 挡不住任务管理器强杀 | 用户态钩子的必然结果 |
| 锁定期间按下的修饰键可能"残留" | 按下与抬起都被吞掉，解锁后按一下 `Shift` 即可恢复 |
| 护屏改不了你屏幕上的静态内容 | 深色壁纸、隐藏桌面图标、任务栏自动隐藏、降低亮度仍是 OLED 的主要防烧屏手段 |
| 护屏不接管系统的"屏幕保护程序" | 两者互不冲突；如果你已开了屏保，可以只留一个 |

## 五、编译

不需要 Visual Studio、不需要 dotnet SDK，用的是系统自带的 .NET Framework 编译器：

```powershell
pwsh -File .\build.ps1                 # 产物 bin\FocusKeep.exe
.\bin\FocusKeep.exe --selftest         # 退出码 0 = 全部通过
```

> 构建脚本带 `/codepage:65001`，因为源码是 UTF-8 且含中文，缺这个参数会乱码。
> 注意要用 **PowerShell 7**（`pwsh`）执行：Windows PowerShell 5.1 按 ANSI 读脚本，中文会解析失败。

### 图标怎么来的

四个状态各有一张 256×256 的设计稿，放在 `src/res/`，编译时用 `/resource` 嵌进 exe
（资源名 `FocusKeep.res.icon-*.png`），运行时按托盘实际尺寸高质量缩放：

| 文件 | 状态 |
|---|---|
| `icon-on.png` | 屏幕常亮中（蓝绿） |
| `icon-off.png` | 屏幕常亮已关闭（灰） |
| `icon-on-lock.png` | 常亮中 + 键盘锁定角标 |
| `icon-off-lock.png` | 已关闭 + 键盘锁定角标 |

- **颜色承担状态**（蓝绿 / 灰），**键盘锁定只加右下角红色小锁**，两种状态可以同时显示；
- 托盘图标统一按 64px 出图再由外壳缩放——只给 32px 时 Win11 在 200% 缩放下会画小一圈；
- `src/app.ico` 是 exe 的应用图标（多尺寸 16~256 的 ICO），由 `tools/MakeIcon.cs` 从
  `src/res/icon-on.png` 生成：

```powershell
# 换图标后重新生成 app.ico（编译一次工具即可）
csc /nologo /target:exe /out:tools/make-ico.exe tools/MakeIcon.cs /reference:System.Drawing.dll
.\tools\make-ico.exe .\src\res\icon-on.png .\src\app.ico
```

### 资源占用

- 托盘图标四种状态在启动后懒加载一次，之后只切换引用，不重复渲染、不累积对象；
- 菜单每次打开只重建有变化的项，旧项显式 Dispose，字体缓存复用，避免 GDI 句柄增长；
- OLED 护屏的定时器只在需要时运行（关闭 / 屏幕常亮关闭时直接停掉），平时 5 秒一跳，休息期间 250ms；
- 启动 20 秒后做一次工作集回收，之后每 10 分钟一次，任务管理器里长期稳定在个位数 MB。

## 六、注意事项

- **杀毒软件可能拦**：全局键盘钩子是键盘记录器的典型特征，Defender/360 有一定概率报毒。
- **exe 未签名**，SmartScreen 首次运行可能提示未知发布者。
- 锁定键盘前会弹确认框（默认"否"），避免误触。
- 护屏是纯黑遮罩，**在别的显示器上看起来就是"屏幕黑了"**；用 `--blank-preview` 可以先演示给同事看，避免误会。
